# Park Scouts

One-page site for the Love Burn Park Scouts at Historic Virginia Key Beach Park.

## Put it on GitHub Pages

1. Create a repository (e.g. `park-scouts`).
2. **Add file → Upload files** and upload the *contents* of this folder (`index.html`, `assets/`, `.nojekyll`, etc.) to the top level.
3. Commit.
4. **Settings → Pages → Deploy from a branch → main / (root) → Save.**

`index.html` is self-contained; the `assets/` folder is used by the tap-to-enlarge collage viewer.

To edit, open `Park Scouts.dc.html` in the design project and re-export.
